### 🚀 Featured Projects

#### 1. 📊 [End-to-End Business Intelligence: Iowa Liquor Sales](https://github.com/AdityaAksar/diageo-sales-analytics)
*A comprehensive BI project analyzing 2+ million sales records.*
* **The Challenge:** Processing massive raw datasets to find revenue trends and product performance.
* **The Solution:** Built an automated ETL pipeline using **Python**, designed a **Star Schema** (Fact & Dimensions), and visualized insights via **Power BI**.
* **Key Result:** Visualized **$442M+ in revenue**, enabling data-driven strategic decisions.
* **Tech:** Python, SQL, Power BI.

#### 2. 🛒 [Retail Sales ETL Pipeline Automation](https://github.com/AdityaAksar/sales-etl-pipeline)
*Simulating a real-world Data Warehouse ingestion process.*
* **The Challenge:** Handling "dirty" raw transaction logs with anomalies and formatting issues.
* **The Solution:** Developed a robust **Python** script for automated cleaning, validation, and transformation.
* **Key Result:** Ensured **100% data integrity** by filtering invalid IDs and enforcing strict data typing before loading.
* **Tech:** Python (Pandas), Jupyter Notebook, Data Validation.
